LangGraph execution model

The loop behind the agent

NSG runs as a LangGraph state machine, not a chain of prompts. The knowledge graph supplies context, the intelligence layer decides, actions are gated, and the outcome returns to memory.

Knowledge graph

Neo4j holds entities, relationships and case history; FAISS recalls the closest prior context.

Intelligence layer

The model plans over retrieved context, chooses tools and checks policy before it moves.

Feedback loop

Outcomes, approvals and audit events are written back, so every run leaves the graph richer.

  1. 01
    Knowledge graph

    Neo4j entities, relationships and history; FAISS recalls the closest prior context.

  2. 02
    Intelligence layer

    The model plans over retrieved context, chooses tools and checks policy before it moves.

  3. 03
    Action

    Bounded writes through MCP tools. Production actions pass a human approval gate.

  4. 04
    Feedback loop

    Outcomes, approvals and audit events are written back into the graph, ready for the next run.
